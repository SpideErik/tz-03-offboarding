## Как воспроизвести

Всё выполняется в виртуальной машине с Debian, скрипты стенда
и приёмки лежат в `~/Downloads`.

```bash
# 1. Развернуть стенд заново
sudo bash ~/Downloads/offboarding-stand.sh

# 2. Выполнить решение
sudo bash audit-user.sh

# 3. Запустить приёмку и сохранить вывод
sudo bash ~/Downloads/offboarding-acceptance.sh | tee acceptance.txt
```
